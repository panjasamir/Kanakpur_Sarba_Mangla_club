# Kanakpur SarbaMangla Seba Sangha — 75 Years

Complete English/Bangla website, ready for GitHub Pages.

## What's included
- A zoomed-out devotional background, 3D-style movement, animated diyas and silent fireworks.
- Dasha Mahavidya section with ten individual devotional illustrations.
- Programme with category filters, photo gallery and full-size image viewer.
- Organisers and members section with optional portraits.
- Past-puja albums with automatic year filters.
- Google Maps, directions and Street View links.

**Read EDITING_GUIDE.md for step-by-step examples for photos, schedules, names and past-puja albums.** Content lists are in data.js. The schedule and registration S/65935 are transcribed from the supplied 2026 poster. Historical photos and member details have not been invented.

## Publish
1. Extract the ZIP.
2. Create a GitHub repository (for example kanakpur-puja).
3. Upload the CONTENTS of this folder, not the ZIP or its enclosing folder. index.html must be at the repository root. Preserve assets/ and its subfolders.
4. In Settings > Pages, choose Deploy from a branch, main, / (root), Save.
5. Wait for deployment and open the live link shown there.

No npm, build step, API key or database is required. The .nojekyll file is included. All code and devotional images are bundled. External Google Fonts/Maps need internet access.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Ten-form interpretation
The ten forms use the traditional Dasha Mahavidya grouping, as named in the supplied programme poster. Names reference: https://magazines.odisha.gov.in/orissareview/2019/Sept-Oct/engpdf/sept-oct-or-2019.pdf
The images are original AI-generated devotional interpretations, not photographs of the club's idols. Chhinnamasta is rendered symbolically without graphic detail.
